# Course Curriculum - reference example

Sample reference written by the REX AI team (house style for curriculum documents).

## Style rules
- Start with the metadata table: department, audience, level, industry, duration, country, framework, prerequisites,
  data sources and update date.
- Outcomes are numbered and start with a measurable action verb (explain, analyse, apply, build, present).
- The module table shows topics, practical work and hours; hours add up to the course total.
- Assessment weights add up to 100%.
- The alignment summary shows coverage per framework and ends with: "Alignment is not accreditation."
