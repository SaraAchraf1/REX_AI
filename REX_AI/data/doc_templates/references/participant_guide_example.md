# Participant Guide - reference example

Sample reference written by the REX AI team (house style for participant guides / workbooks).

## Style rules
- Friendly, encouraging tone; address the learner as "you".
- One chapter per module: what you will learn, key points, activities, reflection questions, space for notes.
- Activities are written as steps the learner can follow without the instructor.
- Reflection questions ask the learner to connect the module to their own work.

## Example module chapter
Module 2: Cleaning and preparing data. In this module you will turn a messy spreadsheet into an analysis-ready
dataset.

Key points
- Check every column's type before you analyse it.
- Missing values need a decision: remove, fill or flag - and you must record which one you chose.

Activity
1. Open the hospital admissions file.
2. Find the three columns with missing values and decide how to treat each one.
3. Write one sentence per decision explaining why.

Reflect
- Where in your own work have missing or wrong values changed a decision?
