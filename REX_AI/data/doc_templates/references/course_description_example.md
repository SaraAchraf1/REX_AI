# Course Description - reference example

Sample reference written by the REX AI team (house style for course descriptions).

## Style rules
- Address the reader as "you"; short sentences; no jargon in the overview.
- The overview answers three questions: what the course is, who it is for, what you can do afterwards.
- Every fact (hours, fees, dates, instructors) comes from the academy catalogue. If a fact is missing, write
  "Contact the academy" - never estimate.
- Never write that a course is accredited or certified by a body. Write "aligned with" a framework instead.

## Example overview
Data Analysis with Python and Power BI is a practical 48-hour course for graduates and business professionals who
want to move into data roles. You will clean real datasets, analyse them with Python and build interactive Power BI
dashboards. By the end you will have a portfolio project you can show to employers.

## Example "What you will learn"
- Clean and transform raw data with pandas
- Explore data and explain findings with clear charts
- Build an interactive dashboard that answers a business question
