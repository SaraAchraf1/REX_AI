# Question Bank - reference example

Sample reference written by the REX AI team (house style for question banks).

## Style rules
- Every question is linked to a learning outcome and a cognitive level (Remember, Understand, Apply, Analyse,
  Evaluate, Create).
- Multiple-choice questions have one correct answer and three plausible distractors of similar length.
- Avoid "all of the above", "none of the above" and negative wording.
- Short-answer and practical questions include a model answer or marking points.
- The question bank is confidential: it is for instructors and is never shared with learners.

## Example items
1. (Multiple choice, Understand) Which technique is used to find the minimum and maximum valid inputs of a field?
   A. Boundary value analysis  B. Statement coverage  C. Code review  D. Load testing.
   Answer: A
2. (Practical, Apply) Design three test cases for a password field that accepts 8-16 characters.
   Marking points: one valid boundary, one invalid below, one invalid above.
