# Learning Outcomes and Assessment Plan - reference example

Sample reference written by the REX AI team (house style for outcome-assessment plans).

## Style rules
- A table maps every outcome to its cognitive level, the modules that teach it and the assessments that measure it.
- Every outcome must be assessed at least once: knowledge outcomes by quizzes or exams, skills outcomes by labs,
  assignments or projects, transferable outcomes by presentations or the capstone.
- Assessment weights add up to 100%.
- State the pass rules (pass mark and attendance) and how feedback is given.
