# Cloud Computing and DevOps Reference Syllabus

Sample reference syllabus compiled by the REX AI team from public cloud certification outlines and job postings.

## Module: Cloud concepts
- Benefits of cloud computing and cloud economics
- Service models (IaaS, PaaS, SaaS) and deployment models
- Global infrastructure: regions and availability zones
- The Well-Architected Framework
Outcome: Explain cloud service and deployment models and their benefits.

## Module: Security in the cloud
- The shared responsibility model
- Identity and access management (IAM) users, roles and policies
- Encryption and compliance programmes
Outcome: Configure IAM following least privilege.

## Module: Core cloud services
- Compute: virtual machines (EC2) and serverless (Lambda)
- Storage: object storage (S3) and block storage
- Databases and networking (VPC)
Outcome: Deploy a simple web application with compute, storage and database services.

## Module: Containers and orchestration
- Docker images and containers
- Kubernetes pods, deployments and services
Outcome: Package an application in a container and run it on Kubernetes.

## Module: CI/CD and infrastructure as code
- Continuous integration and continuous delivery pipelines
- Infrastructure as code with Terraform
- Release and deployment strategies
Outcome: Build a CI/CD pipeline that deploys infrastructure as code.

## Module: Monitoring, billing and cost optimisation
- Monitoring and logging
- Pricing models, billing and cost management tools
- Support plans
Outcome: Monitor a workload and reduce its cost.
