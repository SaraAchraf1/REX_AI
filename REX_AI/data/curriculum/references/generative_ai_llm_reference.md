# Generative AI and LLM Applications Reference Syllabus

Sample reference syllabus compiled by the REX AI team from public course outlines (deep learning lecture
notes such as MIT OCW 6.7960 are indexed separately in the same collection).

## Module: How large language models work
- Tokens, embeddings and the transformer architecture
- Self-attention in plain language
- Pre-training, fine-tuning and instruction tuning
- Capabilities and limits: hallucination, context windows
Outcome: Explain how a large language model generates text and where it fails.

## Module: Prompt engineering
- Instructions, examples and output formats
- Few-shot and chain-of-thought prompting
- Structured outputs (JSON) and validation
Outcome: Design prompts that produce reliable structured outputs.

## Module: Retrieval-augmented generation (RAG)
- Chunking documents and building embeddings
- Vector databases and semantic search
- Grounding answers and citing sources
- Evaluating retrieval quality
Outcome: Build a RAG application that answers questions from company documents with citations.

## Module: Building LLM applications
- Calling LLM APIs from Python
- Tools, function calling and simple agents
- Building a chat interface with Streamlit
Outcome: Develop and deploy a small LLM-powered application.

## Module: Responsible and secure generative AI
- Bias, privacy and data protection
- Prompt injection and output filtering
- Human review of generated content
Outcome: Evaluate an LLM application for safety and responsible use.
