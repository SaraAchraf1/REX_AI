# Data Analysis Reference Syllabus

Sample reference syllabus compiled by the REX AI team from public course outlines and job postings.
Replace with academy-approved references before real use.

## Module: Data analysis foundations
- The data analysis lifecycle: ask, prepare, process, analyse, share, act
- Types of data: structured, semi-structured, unstructured
- Spreadsheet skills for analysts: formulas, lookups, pivot tables
- Framing business questions as analysis questions
Outcome: Describe the stages of a data analysis project and the role of the analyst.

## Module: SQL for analysis
- Selecting, filtering and sorting data
- Aggregations with GROUP BY and HAVING
- Joining tables and handling missing keys
- Common table expressions and window functions
Outcome: Write SQL queries that answer business questions from relational data.

## Module: Data cleaning and transformation
- Detecting missing values, duplicates and outliers
- Data types, parsing dates and text normalisation
- Reshaping data: merge, pivot, melt
- Documenting cleaning steps for reproducibility
Outcome: Clean and transform a raw dataset into an analysis-ready table.

## Module: Exploratory data analysis and statistics
- Descriptive statistics: mean, median, spread, distribution
- Correlation versus causation
- Sampling, confidence and simple hypothesis tests
- Exploring data with pandas
Outcome: Analyse a dataset with descriptive statistics and explain the findings.

## Module: Data visualisation and dashboards
- Choosing the right chart for the question
- Dashboard design principles and KPIs
- Building interactive dashboards in Power BI
- Data modelling and relationships for reporting
Outcome: Build a dashboard that tracks key performance indicators.

## Module: Storytelling and communicating insights
- Structuring a data story for decision makers
- Presenting uncertainty honestly
- Data privacy and ethical use of data
Outcome: Present analysis results and recommendations to non-technical stakeholders.

## Practical project ideas
- Sales performance dashboard for a retail chain
- Customer churn exploration for a telecom operator
- Public dataset analysis (government open data) with a written report
