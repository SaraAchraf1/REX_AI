# Software Testing and QA Reference Syllabus

Sample reference syllabus compiled by the REX AI team; topic order follows the public ISTQB Foundation
Level outline. Alignment only - it does not make a course ISTQB-accredited.

## Module: Fundamentals of testing
- Why testing is necessary and the cost of defects
- The seven testing principles
- Test activities, testware and test roles
- Essential skills and good practices of testers
Outcome: Explain the testing principles and the main test activities.

## Module: Testing throughout the software development lifecycle
- Testing in sequential, iterative and agile SDLC models
- Test levels: component, integration, system, acceptance
- Test types: functional, non-functional, black-box and white-box
- Confirmation testing, regression testing and maintenance testing
- Shift-left and DevOps practices
Outcome: Compare test levels and test types and choose them for a project.

## Module: Static testing
- Work products that can be examined by static testing
- The review process and review types
- Static analysis tools
Outcome: Run a structured review of a requirements document.

## Module: Test analysis and design
- Equivalence partitioning and boundary value analysis
- Decision table testing and state transition testing
- Statement and branch coverage
- Exploratory testing and checklist-based testing
- Acceptance test-driven development
Outcome: Design test cases with black-box and white-box test techniques.

## Module: Managing the test activities
- Test planning and test estimation
- Risk-based testing
- Test monitoring, control and completion reports
- Defect management and writing good defect reports
Outcome: Write a test plan and a defect report for a web application.

## Module: Test tools and automation
- Tool support for testing
- UI test automation with Selenium or Playwright
- API testing with Postman
- Benefits and risks of test automation
Outcome: Automate regression tests for a web application.
